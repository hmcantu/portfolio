# Personal Portfolio

A personal portfolio website built with React, TypeScript, and Vite. Displays personal details, featured projects with interactive controls, categorized technical skills, and contact links.

## 🚀 Live Site

[View Portfolio Site](https://portfolio-git-sprint-12-cantu3.vercel.app)

## 🛠️ Tech Stack

- **Frontend**: React, TypeScript, Vite, CSS
- **Tooling**: ESLint, Prettier
- **Deployment**: Vercel
